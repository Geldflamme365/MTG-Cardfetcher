Was kann der Cardfetcher?

Kartensuche

Suche direkt über die Scryfall API nach Kartenname, Typ oder anderen Qüry-Teilen.

Oracle Text

Zeigt den offiziellen Oracle Text der gewählten Karte in einer lesbaren Detailansicht.

Vergangene Versionen

Lade frühere Prints einer Karte und springe direkt in eine bestimmte Version.

Collection

Speichere Karten lokal im Browser (localStorage), öffne sie später erneut oder entferne sie wieder.

Oracle Tags & Scryfall-Suche

Oracle Tags (grob erklärt)

Oracle-Texte sind die offiziellen, aktüllen Regeltexte einer Karte. Damit kannst du Karten auch dann korrekt verstehen, wenn ältere Drucke andere Formulierungen haben.

Wichtig: Für Regeln gilt immer der Oracle-Text, nicht nur der aufgedruckte Text einer alten Version.

Scryfall Syntax Suche

Mit Scryfall-Qürys filterst du sehr gezielt nach Farbe, Typ, Kosten oder Oracle-Inhalten.

c:u t:creature mv<=3 t:instant o:\"draw a card\"
